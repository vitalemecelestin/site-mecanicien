# Site d'un mécanicien automobile

Bon prix. Bon travail. Bonne route.

Site d'une seule page, sans dépendance : services, décodeur de bruits et de témoins du tableau de bord,
avant/après, estimation avec taxes, rappel de vidange, pneus d'hiver et prise de rendez-vous.

- `index.html` : la source.
- `docs/` : la version en ligne (GitHub Pages), produite par `construire.ps1`.

Le nom, le téléphone, le secteur et les heures sont provisoires : ils se changent dans l'objet `CONFIG`
au début du script de `index.html`. Les prix (`SERVICES`) sont des exemples à ajuster.
